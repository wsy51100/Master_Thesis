THE IDEA

Visual knowledge. LiDAR-only operation.

Semantic maps connect the geometry of a scene with the categories that describe it. This thesis develops a framework that transfers visual information into a LiDAR semantic predictor and uses its outputs to build a persistent semantic neural map. During training, frozen DINOv3 image descriptors are aligned with LiDAR points and combined with hierarchical geometric features in a trainable fusion teacher. Multi-scale knowledge distillation transfers image-conditioned predictions to a LiDAR student, while class-weighted supervision accounts for the long-tailed category distribution.

Deployment retains the student and its main classifier, requiring LiDAR input alone. After geometric registration, the predicted labels supervise PIN-SLAM's native semantic decoder and shared neural point features. The student achieves 64.13% mIoU on SemanticKITTI validation sequence 08 and 60.78% when reflectance is unavailable. On the IPB validation frames, the fine-tuned student achieves 43.78% mIoU using LiDAR alone. The integrated system connects image-assisted semantic learning with queryable neural scene mapping.

METHOD OVERVIEW

Learn with images. Map with LiDAR.

A training-time visual teacher connects a point-cloud student to persistent semantic mapping.

01

Learn from visual features

Calibrated image–LiDAR correspondences associate frozen DINOv3 descriptors with scan points. A trainable fusion teacher combines them with four stages of point–voxel features.

02

Deploy the LiDAR student

Class-weighted segmentation and multi-head distillation train 19-class predictions. Inference uses one LiDAR scan, with an explicit availability flag for reflectance.

03

Learn a semantic neural map

Original point indices preserve label correspondence. After tracking, the predictions supervise the native map decoder and shared features for semantic scene queries.
