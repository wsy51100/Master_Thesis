# Template attribution

This local academic project page adapts the HTML section structure, hero/resource
layout and Bulma styling of [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template),
which was adapted from the [Nerfies project page](https://nerfies.github.io/).
The visual direction follows the classic academic layout used by
[Wheat3DGS](https://joaquin-gajardo.github.io/wheat3dgs/).

Upstream template website licence: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
The visible footer retains both source links and the template licence.
The upstream README is preserved in `sources/TEMPLATE_README.md`.

Modifications: thesis-specific prose and tables; self-contained local assets;
classic white/grey academic styling; responsive layout; a new vector overview;
accessible result tabs, figure enlargement, resource-placeholder dialogs and
BibTeX copying. No template-author photos, example videos, tracking scripts or
placeholder paper links are used.

Research images are copied from the user's existing thesis materials. Their
source files, conversions and hashes are in `sources/ASSET_PROVENANCE.json`.
The new `pipeline.svg` and `favicon.svg` are code-authored explanatory graphics.
No new experiment, scientific output, or synthetic result image was generated.

The thesis PDF, code/model release, and research-asset licences are to be specified
by their respective authors/releases; the template licence is not a declaration
of the final thesis PDF's licence.
